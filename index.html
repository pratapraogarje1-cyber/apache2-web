UNDER THE HOOD

A simple architecture.
Purposeful choices.

This site uses a lightweight static architecture to keep hosting simple and avoid adding a server that the site does not need.

  • ✓HTTPS at the edgeCloudFront uses the ACM certificate for the custom domain.
  • ✓Private S3 originUse Origin Access Control (OAC) so the bucket can remain private.
  • ✓Cost-aware by designNo EC2 instance or database is needed for a static portfolio.
